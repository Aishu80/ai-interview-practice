# AI Interview Practice Platform

Upload your resume and practice with AI-generated personalized interview questions. Get rubric-based feedback on both MCQ and written assessments.

## Features
- Resume-based personalized questions
- 20 MCQs with progressive/adaptive difficulty
- Written assessment with 8-domain rubric evaluation
- Performance charts and downloadable reports
- Demo mode works without API key
